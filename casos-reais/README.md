# Casos reais (para testes)

Aqui ficam PDFs de processos reais e a minuta que o Studio gerou, para eu testar a extensão e o Studio com material de verdade.

## Como enviar
1. Crie uma pasta com data e um apelido, sem nome de parte: `2026-11-10-suspensao-sentenca-indevida/`.
2. Coloque dentro (veja `_modelo/`):
   - `autos.pdf` — o PDF do processo (como saiu do Projudi);
   - `minuta-studio.txt` — a minuta que o Studio gerou;
   - `observacoes.md` — o que estava errado e qual seria o ato correto.
3. Avise no chat: "subi o caso X".

## Cuidados
- **O repositório precisa ser PRIVADO.** Confira em Settings do GitHub antes de subir.
- Processo em **segredo de justiça**: anonimize antes (ou não suba).
- O GitHub recusa arquivo acima de **100 MB**; PDFs maiores: envie só o trecho ou compacte.
- Casos com problema conhecido viram teste fixo: o que o Studio errou hoje não pode errar de novo.
